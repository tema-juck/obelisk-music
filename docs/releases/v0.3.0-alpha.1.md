# Obelisk Music v0.3.0-alpha.1

Published release. Its package version is `0.3.0a1`, and its Git tag spelling is
`v0.3.0-alpha.1`. This release and its tag remain unchanged. The F1 playback
hotfix is prepared separately in [alpha.2](v0.3.0-alpha.2.md).

## Search and music experience

- Press `/` to search Spotify. F1/F2/F3 select tracks, albums, or artists. Input
  debounces for 300 ms; typing does not trigger playback shortcuts.
- Open artist albums and album tracks, retaining pagination and cached pages.
  Enter plays the chosen search URI or the album context at its original offset.
- Use `a` for the selected track's album and `A` for its first credited artist.
  Escape restores the previous view, focus, and row selection.
- Now Playing advances known elapsed time locally, handles pause/resume, and never
  exceeds duration. Spotify polling frequency stays unchanged.
- Choose `midnight` or `mono` in `[appearance]`; restart after changing the theme.
- Compact layouts retain keyboard controls and Now Playing down to 40×12.

Shared token recovery, rate-limit cooldowns, plain-text metadata, protected
playback mutations, and Spotify Connect remain in use. Catalog reads reject stale
responses, including late same-query cache writes. Shutdown awaits cancelled
workers before closing HTTP resources.

## Installation and upgrading

No Python, uv, or Homebrew is needed for standalone installations. The reviewed
installer can select `sh install.sh --version v0.3.0-alpha.1` or `--prerelease`.
See README for the current installation instructions. Existing user configuration and keychain
credentials are preserved; no new Client ID or OAuth scopes are required by P2.

Published assets:

| Platform | Archive |
| --- | --- |
| macOS Apple Silicon | `obelisk-v0.3.0-alpha.1-darwin-arm64.tar.gz` |
| macOS Intel | `obelisk-v0.3.0-alpha.1-darwin-amd64.tar.gz` |
| Linux x86_64, glibc | `obelisk-v0.3.0-alpha.1-linux-amd64.tar.gz` |

Each archive contains `obelisk`, `LICENSE`, and `build-info.json`. `SHA256SUMS`
covers all three archives. Verify checksums before installation, using the
[installation guide](../installation.md#verify-release-checksums-manually).
macOS binaries use ad-hoc signing; Developer ID signing/notarization is not
provided. Linux targets the Ubuntu 22.04 glibc baseline, not Alpine/musl.

## Known limitations and live sign-off

Spotify Premium and a controllable Spotify Connect device are required for
playback. Development Mode, account, and market restrictions can deny catalog
access. Search/artist album page sizes and search offset limits follow the
current API; inaccessible content does not trigger a workaround or reauthorization.
No related-artist/top-track/recommendation endpoints are used.

Elapsed time is an estimate between polls; external playback changes reconcile
on the next update. Cached pages can become stale after external edits; refresh
the view. Duplicate URI occurrences share the playing indicator.

Automated tests use mocked Spotify and no real credentials. Complete the
[live account checklist](../music-experience.md#live-smoke-checklist) for search,
pagination, artist/album playback, devices, pause/resume, failure recovery, both
themes, focus restoration, and all four terminal sizes before live sign-off.
