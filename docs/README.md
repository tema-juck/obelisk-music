Historical [alpha.1](releases/v0.3.0-alpha.1.md) and
[alpha.2](releases/v0.3.0-alpha.2.md) release notes and
[release operations](releases/history.md) retain their original product names and
historical URLs. They record the state at preparation time, including publication
gates; [GitHub Releases](https://github.com/tema-juck/obelisk-player/releases)
shows current publication status.

The public project name is **Obelisk Player**. Compatibility identifiers remain
`obelisk` (CLI), `obelisk-music` (distribution and keychain service), and
`obelisk_music` (Python namespace). Existing configuration, installer receipts,
version metadata, tags, and published assets are preserved.
